# StudyBuddy – Student Buddy Finder

A web-based platform designed to help students connect, find study partners, and communicate with other students.

## About the Project

StudyBuddy is a student-focused web application developed as an academic project. It provides a platform where students can create profiles, discover potential study partners, send requests, and communicate.

## Features

- User Registration and Login
- Student Dashboard
- User Profiles
- Find Study Buddies
- Buddy Requests
- Student Messaging and Chat
- Notifications
- Message Read Receipts

## Technology Stack

- PHP
- MySQL / MariaDB
- HTML
- CSS
- XAMPP (Local Development Environment)

## Local Installation

1. Install XAMPP.
2. Clone or download this repository.
3. Place the project folder inside `C:\xampp\htdocs\`.
4. Start Apache and MySQL from XAMPP.
5. Open phpMyAdmin and import the provided database SQL file.
6. Configure the database connection in `db.php`.
7. Open the project in your browser:

   `http://localhost/Study_Buddy/`
